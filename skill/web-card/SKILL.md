# web-card — 사람 한 명을 소개하는 웹 명함

유저가 확정한 기준:
- **휠을 내리면 장면이 바뀌어야 한다.** 텍스트 이력서형은 반려됐다.
- **사람·사물·공정 자리는 실사 사진.** 선·도형 일러스트로 채우지 않는다(SVG는 아이콘·진행바·지도만).
- **업종마다 뼈대가 달라야 한다.** 한 스켈레톤에 색만 바꾸면 반려된다.

예시 코드: `assets/example/` = 법률사무소 단정(미니멀리즘, 문 열림 진입 → 사건 5단계 핀 → 인감 도장 명함). 사진 포함, 바로 열린다. 단 예시의 영문 모노 라벨(STEP 03 / DRAFTING)은 아래 5절 규칙 이전 제작분이다 — 새 사이트에선 한글로 쓴다.

## 1. 업종 → 네 가지 결정 (코드 전에)

`references/catalog.md`의 15개 표를 먼저 본다. 새 업종은 아래 네 칸이 **기존 줄과 하나도 겹치지 않게** 정한다.

| 결정 | 질문 | 예 (변호사) |
|---|---|---|
| 스타일 1개 | 고객이 이 직업에 기대하는 인상은? (예쁜 것 말고) | 미니멀리즘 — 쿨 종이 + 인주 빨강 |
| 진입 | 이 직업이 손님을 맞는 첫 동작은? | 사무실 문이 좌우로 열림(사진 반분할) |
| 센터피스 | 손님이 겪는 과정 4~6단계는? | 상담→자료→전략→진행→정리, 단계마다 사진 |
| 명함 사물 | 이 직업을 상징하는 손에 쥐는 물건은? | 인감 도장 — 누르면 명함에 찍힘 |

스타일 후보: 미니멀리즘 · 에디토리얼 · 벤토 그리드 · 글래스모피즘 · 그라디언트 메시 · 다크모드 · 뉴모피즘(부분) · 브루탈리즘 · 레트로/Y2K · 3D 인터랙티브. 둘 이상 섞지 않는다.
유저에게 네 칸을 짧게 알리고 바로 진행한다.

## 2. 가상 정보 (레퍼런스용)

판매용 레퍼런스면 이름·약력·연락처·주소·가격을 **그럴듯하게 전부 채운다**. 단:
- 전화 `02-000-0000`·`010-0000-0000` 꼴, 메일 `@<브랜드>.example`, 주소 끝에 "(가상)", 등록번호·사업자번호 0으로.
- 푸터에 "웹 제작 예시 · 상호·인물·연락처·사진은 모두 가상" 고지.
- 실존 업체·자격·수상 이력을 지어내지 않는다. 의료·법률·부동산은 광고 규정 표현 주의("최고", "100% 승소", "완치" 금지).

## 3. 페이지 뼈대

```
진입(2~4초, 클릭·스크롤·키로 건너뛰기, reduced-motion이면 생략)
→ 히어로: 사진 + 고객의 고민 한 문장(은유 금지) + 이름·직함 + CTA 2개(전화/예약)
→ 소개: 사람 사진 + 짧은 약력 + 숫자 3개
→ 서비스/분야 카드
→ 센터피스: 핀 스크롤 4~6컷 (사진 크로스페이드 + 단계 카피 + 진행 표시)
→ 가격(카드) · 후기/사례 · FAQ
→ 오시는 길 · 예약 절차
→ 명함 사물: 만지면 반응 → 연락처 저장(vCard) · 전화 · 문자/카톡 · 지도 · (예약 .ics)
→ 푸터 가상 고지
```
섹션 순서·개수는 업종에 맞게 바꾼다(스냅 작가는 포트폴리오가 먼저, 세무사는 계산기가 가운데).
업종 계산기(기장료·중개보수·인원·회차)가 어울리면 하나 넣는다 — 값의 근거를 함께 보인다.

## 4. 공통 부품

`references/parts.md`에 코드가 있다: 토큰 `:root`, `.rv` 리빌, 진행바, 핀 스크롤 진행도, 사진 `onerror` 폴백, vCard Blob 저장, .ics, 카드 뒤집기+틸트, 토스트, `RM`(reduced-motion) 분기.
사진은 `onload`에 `.ok`로 페이드인, 실패하면 요소를 지우고 자리의 배경색·그라디언트가 대신 보이게 한다 — 사진 없이도 완성돼 보여야 한다.

## 5. 디자인 기준

- 배경 순백·순검정 금지(라이트 #F2~#F7, 다크 #08~#1F). 브랜드색 1개를 면적 10~40%로 쓰는 블록 최소 2곳.
- 본문 14~15px, 한글 제목 700~800·자간 −0.01~−0.02em·줄간 1.15~1.25. 한글 제목체는 업종 성격에 맞춰 고른다(catalog.md 글꼴 열), 본문 Pretendard, `html{font-synthesis:none}`.
- radius 한 계열, transition 160ms ease-out, 큰 모션 480ms `cubic-bezier(.16,1,.3,1)`.
- 영문 모노 대문자 라벨·섹션 번호(Nº 0X)·가는 선 표 금지. 목록·가격도 카드.
- 이펙트는 대표 하나(센터피스) + 작은 장난 하나(명함 사물). 나머지는 정적. 효과가 글씨를 방해하면 효과를 뺀다.

## 6. 검증 — 안 봤으면 완료라고 하지 않는다

```bash
node <스킬>/scripts/verify.mjs http://127.0.0.1:8765/<폴더>/ <출력폴더>
```
뷰포트 320×568 · 375×600 · 390×664 · 430×740 · 1440×900 · 1280×560 · 1024×640에서 진입 → 히어로 → 핀 진행도 0/.25/.5/.75/1 → 명함까지 캡처하고, 가로넘침·콘솔 오류·핀 카피가 화면 밖으로 나가는지 판정한다. 스크린샷을 직접 열어 본다.
낮은 화면(노트북 600대, Safari 툴바)에서 핀 섹션이 가장 잘 깨진다 → `references/pitfalls.md`.
